# Монгол хэл｜モンゴル語学習ノート

全744単語・全48文法項目・152問を網羅した、日本人向けの本格的モンゴル語学習Webアプリケーションです。

エビングハウスの忘却曲線に基づく間隔反復学習（SRS）、メールアドレス不要のユーザー名・パスワード認証、クラウドデータベース同期、オフラインPWA対応を備えています。

---

## 🌟 主な新機能・改善点（v2.0）

### 1. スマートフォン対応 ＆ PWA（PC不要で常時利用可能）
- Vercel、Netlify、Firebaseなどの無料ホスティングにデプロイすることで、自宅のPCの電源が切れていても24時間いつでもスマートフォンから利用可能。
- iPhone（Safari: 「共有」→「ホーム画面に追加」）や Android（Chrome: 「アプリをインストール」）でネイティブアプリ同様にワンタップ起動。
- オフラインキャッシュ（Service Worker Network-First戦略）により、地下鉄や飛行機内などのオフライン環境でも学習を継続可能。

### 2. 複数端末・ブラウザ間でのクラウド自動同期
- PC、スマートフォン、タブレット間で、学習進捗・正答率・間違いノート・忘却曲線スケジュールがリアルタイムで同期されます。
- オフライン時の学習結果は端末内の同期キューに一時保管され、通信が復旧した瞬間に自動的にクラウドへ一括送信されます（データ消失ゼロ保証）。
- 画面上部に同期状態インジケーター（🟢 クラウド同期済 / 🟡 同期中 / 🟠 オフライン一時保存 / ⚪ ローカル保存）を常時表示。

### 3. メールアドレス・Googleアカウント不要の認証システム
- ユーザーが自由に決めたユーザー名（英数字・大文字小文字区別なし）とパスワードだけで登録・ログイン可能。
- Web Crypto APIによる **PBKDF2-SHA256（100,000回ストレッチング＋個別ソルト）** による高強度暗号化ハッシュ保存。平文パスワードは通信・保存ともに一切行いません。
- **ワンタイム復旧コード**: アカウント作成時に発行される16桁の復旧コード（`MN-XXXX-XXXX-XXXX`）により、メールアドレスなしでも安全にパスワードを再設定可能。
- 各ユーザーのデータはRow Level Security（RLS）で完全に分離され、他ユーザーの学習データに干渉することはできません。

### 4. エビングハウスの忘却曲線・間隔反復学習（SRS）
- 単語を一度正解しただけで「習得完了」とせず、記憶の定着度合いに応じて復習間隔を自動調整（初回 → 1日後 → 3日後 → 7日後 → 14日後 → 30日後 → 60日後 → 90日後）。
- 経過日数と安定度から**忘却リスク（0%〜100%）**を動的に算出し、記憶減衰前に自動的に復習対象としてサジェスト。
- 単語ごとの保存データ：最終学習日、学習回数、正解回数、不正解回数、正答率、現在の習熟度Lv（0〜8）、次回復習日、復習間隔、忘却リスク。

### 5. 今日やるべきことが一目でわかるホーム画面
1. **忘却曲線 復習予定**: 本日の復習期日を迎えた単語数と、1クリック復習開始ボタン
2. **高忘却リスク単語**: 記憶保持率が低下している単語の集中特訓
3. **間違いノート**: 未克服の苦手問題数と弱点集中ドリル
4. **今日の学習目標進捗**: プログレスバー（目標20問に対する達成度）
5. **習熟度分布**: 習得済(Lv.6+)、定着中(Lv.3-5)、初見(Lv.1-2)、未学習の4色グラデーションバー
6. **累計学習単語数 / 累計正答率 / 連続学習日数（ストリーク）**

### 6. 間違いノート（履歴の永続保存 ＆ 弱点克服）
- 「過去の間違い履歴（累計誤答回数・最終誤答日時）」と「現在の未克服復習対象」を分離管理。
- 復習で正解しても過去の誤答履歴は消去されず、累計分析に反映されます。
- 間違えた問題だけを集めた特訓テスト、単語別・文法別・格変化別の絞り込みを完備。

## 🚀 クラウド同期（Supabase）のセットアップ手順

本アプリは、設定不要の「ローカル保存モード」でも全機能が動作しますが、Supabaseに接続することでスマホ・PC間の自動同期が有効になります。

1. **Supabaseでプロジェクトを作成**
   - [supabase.com](https://supabase.com)（無料プラン対応）でサインアップし、新しいプロジェクトを作成します。
2. **データベーステーブルの作成**
   - 左側メニューの「SQL Editor」を開きます。
   - 本プロジェクトに含まれる `supabase_schema.sql` の内容をコピー＆ペーストして「Run」を実行します。
   - `user_accounts`, `user_word_progress`, `user_mistakes`, `user_history` の各テーブルとRLSポリシーが一括作成されます。
3. **アプリに接続情報を設定**
   - Supabaseの「Project Settings」→「API」を開きます。
   - 本アプリ画面右上の「☁️ 同期ステータス」ボタンをクリック。
   - **Project URL** と **Project API keys (anon public)** を貼り付けて「設定を保存して同期」をクリックします。
   - これで、スマートフォンや別PCから同じユーザー名でログインするだけで全データが同期されます！

## 🌐 インターネット公開手順（スマートフォンから24時間アクセス）

### 選択肢A: Vercel（最も推奨・1分で完了）
1. [vercel.com](https://vercel.com) で無料アカウントを作成。
2. プロジェクトフォルダをGitHubリポジトリにプッシュするか、`vercel` CLIで `vercel --prod` を実行。
3. （同梱の `vercel.json` が自動認識され、HTTPS対応URLが即座に発行されます）

### 選択肢B: Netlify
1. [netlify.com](https://netlify.com) にログイン。
2. プロジェクトフォルダをドラッグ＆ドロップ（またはGit連携）。
3. 同梱の `netlify.toml` により、SPAリダイレクトとHTTPSが自動構成されます。

## 💻 PCでのローカル起動方法

- **最も簡単な起動（ブラウザ直結）**
  `open_app.bat` をダブルクリック（サーバー起動不要・オフラインで直ちに起動）。
- **ローカルHTTPサーバーで起動**
  `start_app.bat` をダブルクリック（ポート5173でサーバー起動＋ブラウザ自動オープン）。
